# Click Before Tick (CBT) - Geometry Dash Mod

A Geode mod with a game speed (TPS) multiplier and a safe mode. Click-before-tick input handling is still a work in progress.

## Safe mode
When enabled (default), features only run in the editor, practice mode and test mode.

## Building
Requires the Geode SDK (`GEODE_SDK` env var set), CMake 3.21+ and a C++20 compiler.

```
geode build
```
